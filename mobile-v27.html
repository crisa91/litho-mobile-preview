Ρυθμίσεις

Γλώσσα / Language

Η επιλεγμένη γλώσσα εφαρμόζεται και στην εξαγωγή PDF αυτοψιών. Τα κείμενα που καταχωρίζεις εσύ δεν μεταφράζονται αυτόματα.

Αντίγραφο ασφαλείας

Εξαγωγή όλων των έργων και εργασιών σε αρχείο JSON ή επαναφορά από προηγούμενο αντίγραφο.

Η εισαγωγή αντικαθιστά τα υπάρχοντα δεδομένα μετά από επιβεβαίωση.

Διαγνωστικά

Προαιρετική καταγραφή τεχνικών σφαλμάτων χωρίς ονόματα, ΑΦΜ ή περιεχόμενο έργων. Όταν είναι ανενεργή, δεν εκτελείται προαιρετική καταγραφή.

Δοκιμαστικό έργο / Demo project

Δημιουργεί ξεχωριστό έργο με ιδιοκτήτη, μηχανικούς, έγγραφα, αυτοψίες, εργασίες, ραντεβού, σημειώσεις, φάσεις, ζητήματα και κάτοψη με pins. Δεν διαγράφει τα υπάρχοντα έργα σου.

Cloud Sync

Δεν έχει συνδεθεί ακόμη λογαριασμός Supabase. Οι αλλαγές παραμένουν σε αυτή τη συσκευή.

Αποθήκευση

Offline δεδομένα στον συγκεκριμένο browser (localStorage). Δεν γίνεται συγχρονισμός μεταξύ συσκευών.

Μην αποθηκεύεις ευαίσθητα στοιχεία πελατών σε κοινόχρηστη συσκευή. Η διαγραφή δεδομένων browser μπορεί να σβήσει τα έργα σου.
